## Описание варианта и алгоритма

* **Компоненты:** `APP`, `LOG`, `QUE`.
* **Порядок записи:** Время–компонент–значение. Разделитель: точка с запятой.
* **Тип последовательности (1):** Записи идут строго по времени; на каждом отсчёте присутствуют все три компонента.
* **Производный показатель** $Q$ **(Симметрированное относительное изменение):**
  $$Q[i] = \frac{X[i] - X[i-k]}{\frac{|X[i]| + |X[i-k]|}{2}}, \quad k = 1$$
* **Правило состояния компонента (Выход за диапазон):** Если $Q < L_{min}$ или $Q > L_{max}$ (при $L = 1.5$), состояние — **«ТРЕВОГА»**, иначе — **«НОРМА»**.
* **Правило инцидента (Большинство):** Инцидент возникает, если большинство присутствующих компонентов ($\ge 2$ из 3) находятся в проблемном состоянии («ТРЕВОГА»).

## Ручной расчёт

### 1. Компонент APP
* **Данные:** $[41.9, 47.8, 48.3, 48.8, 49.3]$
* **Показатели:**
  * $Q_1 = \frac{47.8 - 41.9}{\frac{47.8 + 41.9}{2}} \approx 0.13155$
  * $Q_2 = \frac{48.3 - 47.8}{\frac{48.3 + 47.8}{2}} \approx 0.01041$
  * $Q_3 = \frac{48.8 - 48.3}{\frac{48.8 + 48.3}{2}} \approx 0.01030$
  * $Q_4 = \frac{49.3 - 48.8}{\frac{49.3 + 48.8}{2}} \approx 0.01019$
* **Проверка:** Все значения в диапазоне $[-1.5; 1.5]$ $\rightarrow$ **НОРМА**

### 2. Компонент LOG
* **Данные:** $[57.4, 55.4, 53.4, 51.4, 54.8]$
* **Показатели:**
  * $Q_1 = \frac{55.4 - 57.4}{\frac{55.4 + 57.4}{2}} \approx -0.03546$
  * $Q_2 = \frac{53.4 - 55.4}{\frac{53.4 + 55.4}{2}} \approx -0.03676$
  * $Q_3 = \frac{51.4 - 53.4}{\frac{51.4 + 53.4}{2}} \approx -0.03817$
  * $Q_4 = \frac{54.8 - 51.4}{\frac{54.8 + 51.4}{2}} \approx 0.06403$
* **Проверка:** Все значения в диапазоне $[-1.5; 1.5]$ $\rightarrow$ **НОРМА**

### 3. Компонент QUE
* **Данные:** $[30.2, 29.5, 34.1, 33.4, 32.6]$
* **Показатели:**
  * $Q_1 = \frac{29.5 - 30.2}{\frac{29.5 + 30.2}{2}} \approx -0.02345$
  * $Q_2 = \frac{34.1 - 29.5}{\frac{34.1 + 29.5}{2}} \approx 0.14465$
  * $Q_3 = \frac{33.4 - 34.1}{\frac{33.4 + 34.1}{2}} \approx -0.02074$
  * $Q_4 = \frac{32.6 - 33.4}{\frac{32.6 + 33.4}{2}} \approx -0.02424$
* **Проверка:** Все значения в диапазоне $[-1.5; 1.5]$ $\rightarrow$ **НОРМА**
