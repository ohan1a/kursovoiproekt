Разделитель: точка с запятой.Тип последовательности (1): Записи идут строго по времени; на каждом отсчёте присутствуют все три компонента.Строка телеметрии:
1;APP;41.9;1;LOG;57.4;1;QUE;30.2;2;APP;47.8;2;LOG;55.4;2;QUE;29.5;3;APP;48.3;3;LOG;53.4;3;QUE;34.1;4;APP;48.8;4;LOG;51.4;4;QUE;33.4;5;APP;49.3;5;LOG;54.8;5;QUE;32.6Производный показатель $Q$ (Симметрированное относительное изменение):
$$Q[i] = \frac{X[i] - X[i-k]}{\frac{\vert{}X[i]\vert{} + \vert{}X[i-k]\vert{}}{2}}, \quad k = 1$$Правило состояния компонента (Выход за диапазон): Если $Q < L_{min}$ или $Q > L_{max}$ (при $L = 1.5$, диапазон допустимых значений $[-1.5; 1.5]$), состояние компонента — «ТРЕВОГА», иначе — «НОРМА».Правило инцидента (Большинство): Инцидент фиксируется, если большинство присутствующих компонентов ($\ge 2$ из 3) находятся в проблемном состоянии («ТРЕВОГА»).Структура Incident:typedef struct { int time; int type; int first; int second; } Incident;
